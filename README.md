# Formation Apnée du Sommeil — Site de présentation

Site de présentation de la formation certifiante 40h **Prescription PPC & OAM**,
destinée aux médecins souhaitant devenir prescripteurs dans la prise en charge du SAHOS.

## Contenu

- `index.html` — Page principale (hero, programme, parcours, tarif, FAQ)
- `style.css` — Design responsive
- `script.js` — Accordéons interactifs

## Utilisation

Ouvrir `index.html` dans un navigateur — aucune installation requise.

## Conformité

Formation conforme HAS / SFRMS / AASM / Arrêté du 13/12/2017 / FST Médecine du Sommeil.
